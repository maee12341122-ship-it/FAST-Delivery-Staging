# FAST – تعز إكسبرس

تطبيق Flutter للعميل والمشرف والمندوب، مع Supabase وEdge Functions.

## ابدأ من هنا

اقرأ **`README_DEPLOY_AR.md` بالكامل** قبل تشغيل النسخة. يحتوي على خطوات ترحيل قاعدة البيانات اليدوية، إعداد حساب المدير، نشر Edge Functions، حماية مفاتيح الخدمات، وإعداد توقيع Android في Codemagic.

## الملفات المهمة

- `lib/`: تطبيق Flutter وواجهاته الحالية.
- `supabase/migrations/`: ترحيل SQL المتوافق مع الجداول اليدوية الحالية.
- `supabase/functions/`: وظائف خادمية محمية للطلبات والمندوبين.
- `codemagic.yaml`: Workflow لبناء APK اختباري وAAB موقّع للنشر بعد إعداد Keystore.
- `backend/`: Backend Node.js منفصل يستخدم مخطط PostgreSQL مستقلاً؛ لا تشغّله فوق الجداول اليدوية في Supabase قبل توحيد المخطط.
- `PROJECT_AUDIT_AR.md`: تقرير الفحص والقيود الحالية.
- `CHANGELOG_FAST_AR.md`: سجل التعديلات.

## ملاحظة عن جاهزية النشر

هذه حزمة Staging مرشحة للاختبار وليست إصداراً إنتاجياً معتمداً بعد. لم يتوفر Flutter/Dart SDK في بيئة تجهيز الحزمة، ولم يتم الاتصال بمشروع Supabase الحي. يجب تشغيل الترحيل ونشر Edge Functions وإعداد حساب المدير والتوقيع ثم تنفيذ `flutter analyze` وبناء واختبار التطبيق على أجهزة فعلية قبل النشر.
